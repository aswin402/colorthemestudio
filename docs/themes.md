# Themes & Typography Engine

ColorTheme Studio features an incredibly powerful component generation engine driven by **48 handcrafted presets** and over **30 built-in Google and system fonts**.

These presets aren't just mere color swaps—they are total systemic overhauls affecting:
- **Core Typography** (Headers, Body, Monospace)
- **Geometry & Border Radii** (from `none` to completely `full` pills)
- **Effects & Depth** (Elevation shadows, inset simulations)
- **Layout Density** (Compact UI vs Spacious dashboards)
- **Theme Temperature** (Controlling how light/dark mode neutral grays are tinted—`warmer`, `cooler`, or `natural`).

## 🏗️ 10 Core Foundations
These are baseline, functional themes derived from popular design systems (like Shadcn).
- **Shadcn Slate / Shadcn Zinc**: Strict, professional grayscale defaults.
- **Modern Blue / Pro Indigo**: Standard tech SaaS starting points with deep blues.
